# Marketing Setup

How to claim free organic listings and register the product feeds this repo
already generates. No code changes needed for any of this — it's all
dashboard configuration on Google's / TikTok's side.

## 1. Google Search Console

1. Go to search.google.com/search-console, add the site as a URL-prefix
   property using the deployed origin (`NEXT_PUBLIC_SITE_URL`).
2. Verify ownership (the HTML-tag or DNS method both work fine on Vercel).
3. Sitemaps → submit `sitemap.xml` (resolves to
   `{SITE_URL}/sitemap.xml` — generated by `apps/web/src/app/sitemap.ts`,
   includes every static page plus every active/coming-soon product,
   refreshed hourly).

## 2. Google Merchant Center (free Shopping listings)

1. Create an account at merchants.google.com for the business.
2. Business info → confirm the business name, address (Stanbank House,
   Moi Avenue, Nairobi), and website.
3. Products → Feeds → add a feed → "Scheduled fetch" → point it at:
   `{SITE_URL}/api/feeds/google`
   (Content-Type: `application/xml`, RSS 2.0 + Google's `g:` namespace,
   built by `apps/web/src/lib/feeds.ts` → `buildGoogleFeedXML`, revalidated
   hourly.) Set the fetch schedule to daily.
4. Fields included per product: id, title, description, link, image_link
   (+ up to 10 additional images), price (KES), availability, condition
   (new), brand (Elite Style Co.), product_type, and
   google_product_category (mapped from our internal category — see
   `GOOGLE_PRODUCT_CATEGORY` in `feeds.ts`).
5. Products with zero images are automatically excluded from the feed
   (Merchant Center would reject them anyway).
6. Known gap: no GTIN/MPN per product (we don't track manufacturer
   identifiers). This can surface a "missing identifier" quality warning
   for apparel but shouldn't block ingestion since brand is populated.

## 3. TikTok Catalog (TikTok Shop / Ads Catalog Manager)

1. business.tiktok.com → Assets → Catalog → create a catalog (Ecommerce).
2. Data feed → add feed → Scheduled → point it at:
   `{SITE_URL}/api/feeds/tiktok`
   (Content-Type: `text/csv`, columns: sku_id, title, description,
   availability, condition, price, link, image_link, brand,
   google_product_category — this exact column set/order matches TikTok's
   required catalog fields.)
3. Set the fetch schedule to daily.

## 4. Verifying the feeds manually

```
curl -s {SITE_URL}/api/feeds/google | head -40
curl -s {SITE_URL}/api/feeds/tiktok | head -5
```

Both are covered by unit tests (`apps/web/tests/feeds.test.ts`) that assert
the envelope, field escaping, and availability/price formatting — run
`npm test` in `apps/web` if you change `feeds.ts`.
